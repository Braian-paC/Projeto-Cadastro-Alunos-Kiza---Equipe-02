# Sistema de Cadastro de Alunos - Kiza Dev - Equipe 2
# Sobre o projeto

Desenvolvemos um site de **Cadastro de Alunos** onde o aluno em questão realiza o seu cadastro com as seguintes informações:
- Nome Completo
- CPF
- Senha
- Email

No sistema, dará erro ou inválido SE:
- Nome for igual a outro no banco de dados.
- CPF não for válido.
- Senha não conferir com o campo de **confirmar senha**.
- Email for igual a outro no banco de dados.

Após isso, as informações serão salvas em um banco de dados online hospedado pelo Railway e você poderá realizar seu login utilizando o **email** e a **senha**.<br>
Na página "home.php" terá 3 ícones ao lado esquerdo que direcionam para as seguintes páginas:
- |🏠 -> home.php
- |👥 -> home.php
    - A mesma página, porém, você conseguira ver os alunos cadastrados e excluí-los ou modificar suas credenciais.
- |🚪 -> login.php

# Como inicializar o projeto
Se você estiver pelo **VS Code**, faça o seguinte:
1. Instale a extensão **PHP Server**.
2. Vá no arquivo **index.php** na pasta principal do projeto.
3. Pressione simultâneamente as teclas **CTRL** + **SHIFT** + **P**.
4. Na barra que aparecer, digite e encontre a opção **PHP Server: Serve Project**.
5. Após clicar nessa opção, o servidor se iniciará em seu navegador, e pronto.

Se você estiver utilizando o terminal:
1. Direcione-se à pasta principal do projeto com o comando **cd**
2. Digite o comando **php -S localhost:8000** ou **php -S localhost:8080**
3. Abra o navegador e acesse: http://localhost:8000.
